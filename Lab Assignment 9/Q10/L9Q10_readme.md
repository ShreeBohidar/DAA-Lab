## Problem Statement
[Greedy Superstring Conjecture] (Open Unsolved Problem): Given a set of n strings S = {s1, s2, ..., sn}, find the shortest single string that contains every si as a substring. You are advised to explore more on this problem to develop an insight.
Background and current status of the conjecture: The conjecture formulated nearly four decades ago hypothesised that the classic greedy algorithm (repeatedly merging the pair with the maximum overlap) always yields a superstring no more than twice the length of the optimal solution (2-approximation). A September 2026 paper titled "Disproving the Greedy Superstring Conjecture" published on ArXiV demonstrated that the approximation ratio for instances where input strings have an even length k >= 10 is at least (9k + 2) / (4k + 4), establishing a limit of 9/4 (2.25) as k -> infinity. This conclusively disproves the long-standing 2-approximation claim. By choosing the proper input representation, write a program in C to validate your algorithm and derive the complexity analysis of your algorithm.

## Approach
The Shortest Common Superstring (SCS) problem is an NP-hard optimization problem central to computational biology and data compression. Finding the exact shortest superstring is computationally intractable, making greedy heuristics essential.

1. Substring Elimination:
   - If any input string si is already an exact substring of another string sj, it is redundant and can be immediately eliminated without affecting the minimal superstring length.
2. Suffix-to-Prefix Overlap Calculation:
   - For any two strings a and b, the overlap function `compute_overlap(a, b)` calculates the maximum length k such that the suffix of length k in string a matches the prefix of length k in string b:
     `a[len(a) - k ... len(a) - 1] == b[0 ... k - 1]`
   - Overlap is asymmetric; `compute_overlap(a, b)` is generally not equal to `compute_overlap(b, a)`.
3. Greedy Choice Paradigm:
   - At each step, all ordered pairs of distinct active strings (S[i], S[j]) are evaluated to find the pair with the maximum overlap `max_ov`.
   - The winning pair is merged by taking all of S[i] and appending the non-overlapping remainder `S[j] + max_ov`.
   - The merged string replaces S[i], and S[j] is removed from the active set.
   - This process repeats until exactly one superstring remains.
4. Insights on the Greedy Superstring Conjecture:
   - The 40-year-old conjecture postulated that this greedy heuristic guarantees a 2-approximation, meaning `Length(Greedy) <= 2 * Length(Optimal)`.
   - The disproof establishes a counterexample family with lower bound `(9k + 2) / (4k + 4) -> 2.25` for even length `k >= 10`, showing that local greedy overlap decisions can lead to sub-optimal superstring concatenation.

## Algorithm
1. Read the number of strings n.
2. Read the n strings into a 2D character array `str[][]`.
3. Substring Pruning:
   - Initialize an array `active[]` of size n to 1.
   - For every pair (i, j) with i != j, if `strstr(str[j], str[i]) != NULL`, mark `active[i] = 0`.
   - Copy all remaining active strings into a compact working array `S[][]` and update count.
4. Merge Loop (while count > 1):
   - Initialize `max_ov = -1`, `best_i = -1`, `best_j = -1`.
   - For every distinct ordered pair (i, j) from 0 to count - 1:
     - Compute suffix-to-prefix overlap `ov = compute_overlap(S[i], S[j])`.
     - If `ov > max_ov`, update `max_ov = ov`, `best_i = i`, `best_j = j`.
   - Merge `S[best_i]` and `S[best_j]` by appending `S[best_j] + max_ov` to `S[best_i]`.
   - Remove `S[best_j]` by shifting succeeding strings left in the array.
   - Decrement `count` by 1.
5. Display the final greedy superstring and its total length.

## Pseudocode
Algorithm GreedySuperstring(str[], n):
    Input: Set of n strings str[]
    Output: Shortest superstring approximation generated by greedy merging

    For i <- 0 to n - 1 do
        active[i] <- 1
    End For

    For i <- 0 to n - 1 do
        For j <- 0 to n - 1 do
            If i != j and active[i] == 1 and active[j] == 1 then
                If str[i] is substring of str[j] then
                    active[i] <- 0
                    Break
                End If
            End If
        End For
    End For

    count <- 0
    For i <- 0 to n - 1 do
        If active[i] == 1 then
            S[count] <- str[i]
            count <- count + 1
        End If
    End For

    While count > 1 do
        max_ov <- -1
        best_i <- -1
        best_j <- -1

        For i <- 0 to count - 1 do
            For j <- 0 to count - 1 do
                If i != j then
                    ov <- ComputeOverlap(S[i], S[j])
                    If ov > max_ov then
                        max_ov <- ov
                        best_i <- i
                        best_j <- j
                    End If
                End If
            End For
        End For

        merged_str <- S[best_i] concatenated with S[best_j] from index max_ov onwards
        S[best_i] <- merged_str

        For k <- best_j to count - 2 do
            S[k] <- S[k + 1]
        End For
        count <- count - 1
    End While

    Print "Greedy Superstring: ", S[0]
    Print "Length: ", Length(S[0])
    Return S[0]
End Algorithm

## Complexity Analysis
Let n be the number of strings and L be the maximum length of any input string:
1. Substring Elimination:
   - Testing each pair of strings for substring inclusion takes O(n^2 * L^2) time.
2. Iterative Merging:
   - There are exactly (count - 1) <= (n - 1) merge steps.
   - In each step with m active strings:
     - Testing all ordered pairs involves m * (m - 1) pairs.
     - For each pair, computing the overlap takes O(L^2) comparisons.
     - Finding the maximum overlap takes O(m^2 * L^2) time.
     - Merging strings and shifting the array takes O(m * L) time.
   - Summing across all steps:
     Sum over m from 2 to n of O(m^2 * L^2) = O(n^3 * L^2).
3. Final string length calculation and output take O(n * L) time.

Total Time Complexity:
T(n, L) = O(n^2 * L^2) + O(n^3 * L^2) + O(n * L) = O(n^3 * L^2).

## Conclusion
The greedy superstring algorithm constructs an approximate shortest common superstring by iteratively merging pairs with maximum prefix-suffix overlap. While historically hypothesized to achieve a tight 2-approximation factor, recent advances have disproved the conjecture by demonstrating asymptotic approximation ratios reaching 2.25. The implemented greedy simulation resolves overlapping segments in polynomial O(n^3 * L^2) time, illustrating both the practical utility and theoretical boundaries of the greedy heuristic.
